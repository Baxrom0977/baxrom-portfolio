# Weather Dashboard

Приложение для просмотра погоды в разных городах. Проект создан во время изучения JavaScript: работа с DOM, асинхронными запросами и хранением данных в браузере.

## Возможности

- Поиск городов с подсказками.
- Текущая температура, ощущаемая температура, влажность и скорость ветра.
- Описание погоды с иконкой.
- Прогноз на 7 дней с минимальной и максимальной температурой.
- Добавление и удаление избранных городов.
- Сохранение избранного и последнего выбранного города в localStorage.
- Загрузка Ташкента при первом открытии, если сохранённого города нет.
- Сообщения о загрузке и ошибках.

## Технологии

HTML, CSS и JavaScript без фреймворков. Для запросов используются Fetch API и async/await, для сохранения данных — localStorage.

Данные о городах и погоде предоставляет [Open-Meteo](https://open-meteo.com/).

## Запуск

1. Скачайте проект или клонируйте репозиторий.
2. Откройте папку проекта в VS Code.
3. Запустите index.html через расширение Live Server.

Для получения погоды необходимо подключение к интернету.
